# Overview
Simulation GSEE for drone project.

# Compilation
## Build and Run (Recommended)
In root directory: 
`odin run .`

## Build
In root directory: 
`odin build .`

# Dependencies

# Controls
`r` - Resets scene
`[space]` - Pauses simulation
